# Проєкт data-processing-fullstack-app (Лабораторні роботи)
Цей репозиторій містить вихідний код проєкту, розробленого в рамках виконання лабораторних робіт. Проєкт демонструє еволюцію вебзастосунку від базового бекенду до повноцінної клієнт-серверної архітектури з безпекою та контейнеризацією.
## Технологічний стек
*   **Бекенд:** Java 17+, Spring Boot, Spring Security (JWT), Spring Data JPA.
*   **Фронтенд:** Vue.js, Vite, HTML/CSS/JavaScript.
*   **База даних:** PostgreSQL.
*   **Інфраструктура:** Docker, Docker Compose.
*   **Інструменти збірки:** Maven (backend), npm (frontend).
## Структура репозиторію
Репозиторій розбитий на окремі папки, кожна з яких відповідає певному етапу розробки (лабораторній роботі), а також містить фінальні версії бекенду та фронтенду в кореневих директоріях `backend` та `frontend`.
### Огляд лабораторних робіт
*   **`lab4/` та `lab5/`**: Початкові етапи розробки. Реалізація базового бекенду (`demo` проєкт) на основі Java.
*   **`lab6/`, `lab7/`, `lab8/`**: Розширення архітектури. Додавання клієнтської частини (`frontend` папка) та інтеграція з бекендом.
*   **`lab9/`**: Впровадження підсистеми безпеки. Налаштування Spring Security, генерація та валідація JWT-токенів (робота з автентифікацією).
*   **`lab10/`**: Контейнеризація застосунку. Налаштування Docker та `docker-compose.yml` для одночасного запуску бази даних (PostgreSQL), бекенду (Spring Boot) та фронтенду (Vue.js) у відокремлених контейнерах.
### Основні директорії
*   **`backend/`**: Актуальний код серверної частини (API, бізнес-логіка, конфігурація доступу до БД).
*   **`frontend/`**: Актуальний код клієнтської частини (інтерфейс користувача).
## Як запустити проєкт (через Docker Compose)
Найпростіший спосіб розгорнути одразу весь проєкт (БД + Бекенд + Фронтенд) — скористатися налаштуваннями з `lab10`.
1.  Перейдіть до папки `lab10`:
    ```bash
    cd lab10
    ```
2.  Запустіть контейнери за допомогою Docker Compose:
    ```bash
    docker-compose up -d --build
    ```
3.  Після успішного запуску:
    *   Фронтенд буде доступний за адресою: [http://localhost:5173](http://localhost:5173)
    *   Бекенд (API) буде доступний за адресою: [http://localhost:8080](http://localhost:8080)
    *   База даних PostgreSQL слухатиме порт `5432`.
## Як запустити локально (без Docker)
Якщо ви хочете запустити проєкт локально для розробки та внесення змін:
### Запуск бекенду
1. Впевніться, що у вас встановлено та запущено локальний сервер PostgreSQL.
2. Створіть базу даних з параметрами, які вказані у конфігурації бекенду (`application.properties` або `.yml`).
3. Перейдіть у теку `backend/`.
4. Запустіть проєкт за допомогою Maven:
   ```bash
   mvn spring-boot:run
   ```
### Запуск фронтенду
1. Перейдіть у теку `frontend/`.
2. Встановіть залежності (якщо ви робите це вперше):
   ```bash
   npm install
   ```
3. Запустіть сервер для розробки:
   ```bash
   npm run dev
   ```
## База даних
Ініціалізація бази даних та наповнення початковими даними відбувається через SQL-скрипти (наприклад, `films.sql`, `init.sql`), які знаходяться у директорії бекенду, або автоматично за допомогою Hibernate (`spring.jpa.hibernate.ddl-auto=update`).
